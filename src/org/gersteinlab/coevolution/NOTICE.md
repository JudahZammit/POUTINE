# Vendored third-party source: Gerstein lab *Coevolution*

The five `.java` files under this directory are copied **unmodified** from the Gerstein lab's *Coevolution* system (Yip et al., Bioinformatics 24(2):290-292, 2008; classes by Kevin Yuk-Lap Yip). POUTINE uses them for Newick tree parsing and the tree data model.

**Licence: unknown.** The upstream distribution carries no licence or copyright notice. These files must not be treated as GPL-3 like the rest of the repository, and the repository must not be published to bioconda until this is resolved.
